# Budsy Android build

This commit triggers the repository's GitHub Actions workflow to build the Android project packaged in `Budsy.zip`.

- Workflow: `.github/workflows/android-apk.yml`
- Artifact name: `Budsy-debug-apk`
- Target: OnePlus Nord Buds 3 (non-Pro), Android 16
- Reminder: a successful compile does not prove proprietary earbud controls work on hardware.

Run details: open the repository's Actions tab and select the newest "Build and verify Budsy Android APK" run.
